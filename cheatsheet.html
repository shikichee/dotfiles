dotfiles Cheatsheet

shikichee/dotfiles — GNU Stow | ghq root: ~/src/ | oh-my-zsh + starship + tmux + wezterm + neovim

Tier 1: 毎日使う
repofzf でリポジトリ検索 → cd
vnvim 起動（vi, vim も同じ）
cカレントディレクトリを Cursor で開く
clClaude Code 起動
gstgit status
gpsgit push origin HEAD
gco <branch>git checkout
ga <file>git add
gcgit commit
Tier 2: 毎日〜数日に1回
gg <keyword>git grep（大文字小文字無視）
clone <url>ghq get + cd を一発で
kclone <name>shikichee/<name> をクローン
glgit pull
gdgit diff
gloggit log --oneline --graph
gbgit branch
gh co <PR#>PR をローカルにチェックアウト
Tier 3: tmux（プレフィックス C-s）
C-s |ペイン縦分割
C-s -ペイン横分割
C-s h/j/k/lペイン移動
C-s H/J/K/Lペインリサイズ
C-s r設定リロード
C-s [ → v → yコピーモード → 選択 → ヤンク
C-s C-pペースト
Tier 4: WezTerm
Cmd+pコマンドパレット
Ctrl+Shift+S → [コピーモード（Leader キー）
Tier 5: たまに使うツール
mise installランタイムインストール
lazygitTUI git クライアント
tiggit ログビューア
fzfあいまい検索
ghq list管理中リポジトリ一覧
ポイント
  • repo と v と c で日常の8割カバー
  • oh-my-zsh git エイリアスは Tier 1-2 で十分
  • ローカル追加設定は ~/.local.zsh に書く
  • ghq root は ~/src/
